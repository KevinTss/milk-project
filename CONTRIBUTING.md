# Contributing to Milk

Milk is an open-source initiative. Contributions don't need to involve code.

You can help with:

- 🌱 Researching cafés and plant-based milk options
- 💸 Checking prices and plant-based milk surcharges
- 📍 Adding or correcting place information
- 🔎 User and market research
- 💡 Product ideas
- 🎨 Design
- 📣 Community and activism
- 📝 Documentation
- 💻 Development

## Getting started

### 1. Find something to work on

Check the [GitHub Issues](../../issues) and project board.

Issues labeled `good-first-task` are good places to start.

If you want to work on something that doesn't have an issue yet, create one first so we can discuss it.

### 2. Work on the issue

Assign yourself to the issue when possible.

Keep research, decisions, and useful context documented so others can understand and build on your work.

For research, always distinguish between:

- **Verified information** — supported by a reliable source
- **Unverified information** — something we haven't confirmed yet
- **Assumptions** — ideas that still need to be tested

Never invent missing information.

### 3. Propose your changes

For changes to the repository:

1. Create a branch.
2. Make your changes.
3. Commit them.
4. Open a Pull Request.
5. Link the related issue.

Keep Pull Requests focused on one topic whenever possible.

## Café data

Accuracy matters.

When researching a café, try to verify:

- Plant-based milk availability
- Types of plant-based milk available
- Whether there is a surcharge
- Exact surcharge, if known
- Source of the information
- Date the information was verified

Prefer first-party and recent sources whenever possible.

If information cannot be verified, mark it as **unknown** rather than guessing.

## Documentation

Project documentation lives in [`/docs`](./docs).

Documentation changes follow the same workflow as code: create an issue when appropriate and propose changes through a Pull Request.
